The three things your checklist asks for (smoke tests, a backup-restore drill and the password routine) were run here first, on a stand-in app with the same stack and test data only.

One change I'd suggest to the guide: the domain

Cloud Run's own domain mapping is a Preview feature, and Google's HIPAA guidance says not to use pre-GA offerings with PHI. The gcloud CLI agrees: for fully managed Cloud Run, mapping a domain needs the gcloud beta command group. The plan puts a global external Application Load Balancer with a Google-managed certificate in front instead, then closes the run.app address so the domain is the only way in.
